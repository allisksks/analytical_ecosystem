# Архитектура

Модульный монолит (ТЗ, раздел 5): один Python-сервис с чёткими границами модулей, отдельно запускаемые
воркеры и AI-шлюз. Делить на сервисы можно позже, когда появится нагрузка.

```
React SPA ──► nginx (/api proxy, один origin) ──► Core API (FastAPI)
                                                   ├─ iam: пользователи, проекты, роли, политики, токены
                                                   ├─ audit: журнал входов, изменений прав, запросов, промптов
                                                   ├─ connectors: плагины источников + каталог
                                                   ├─ query: sqlglot-guard (только SELECT), RLS, маскирование PII, лимиты, кэш
                                                   ├─ semantic: метрики/измерения → SQL под диалект источника
                                                   ├─ bi: дашборды, виджеты, сохранённые запросы
                                                   ├─ kb: 7 типов записей, версии, поиск
                                                   ├─ ems: события, версии, валидация, алерты
                                                   ├─ experiments: дизайнер, мощность, байес/частотный расчёт, SRM
                                                   └─ ai: OpenAI-совместимый шлюз, RAG, text-to-SQL
Хранилища платформы: PostgreSQL 16 + pgvector (метаданные, векторы), Valkey (кэш, очереди), ClickHouse (sync-данные)
Хранилища клиента: ClickHouse, PostgreSQL, MySQL, файлы/S3 через DuckDB …
```

## Ключевые решения

| Решение | Почему |
|---|---|
| Авторизация — один модуль политик в бэкенде (`app/modules/iam/policy.py`), проверка «действие + ресурс + проект» на каждом эндпоинте | ТЗ, раздел 2: фронт только скрывает кнопки |
| Встроенная аутентификация (argon2 + JWT, refresh в httpOnly cookie) и режим OIDC (Keycloak/SSO) через переключатель `AUTH_MODE` | пилот без Keycloak ставится за 30 минут; в крупной компании — SSO |
| Все SQL проходят через Query Service: разбор sqlglot, только SELECT, подстановка RLS, маскирование PII, лимит и таймаут, кэш, аудит | единая точка контроля, в т.ч. для SQL от ИИ |
| Valkey вместо Redis | Redis 7.4+ сменил лицензию; Valkey — BSD, совместим по протоколу |
| React 19 + TypeScript 5.9, CSS Modules + CSS-переменные вместо Tailwind | актуальные версии; дизайн-токены прототипа ВКР, тёмная тема переключением атрибута |
| Клиент API генерируется из OpenAPI 3.1 (`openapi-typescript` + `openapi-fetch`) | типы фронта и бэка не расходятся, CI это проверяет |
| Демо-данные — Parquet + DuckDB | платформа работает «из коробки» без внешней БД; тот же генератор грузит ClickHouse |
